# エクステンドワールド - 星詠みの迷宮 -

星の記憶を読み、まだ見ぬ世界を広げていくターン制ダンジョンRPG。
スマートフォン・タブレット・PCのブラウザに対応しています。

## 遊ぶ

[公開ゲームを開く](https://genkun-test.github.io/extend-world-star-dungeon/)

公開URLを開き、主人公を選び、「迷宮に入る」から開始します。
毎回変わる3つの迷宮（全21階）、それぞれの守護者を攻略してください。

- 4人の主人公。星剣士・星術師・星渡り・星祈りで異なる特技と個性。
- 16種の魔物。追跡・疾走・遠距離・毒・凍結・ミミック・召喚する守護者。
- 12種の武器、10種の防具、8種の指輪。特殊効果・鍛冶・装備持ち越し。
- 20種の道具。回復・食事・巻物・種・矢・爆弾・転移・帰還・復活。
- 空腹・状態異常・罠・星泉・商人・魔物の巣・10種の星座。
- 弱った魔物へ食事を差し出し、仲間にする「星の縁」。仲間は1体同行できます。
- 拠点の永久強化、魔物図鑑、星の記憶、旅の記録。3つの星封を解くエンディング。

## 操作

スマートフォン：方向ボタンか迷宮上のタップで移動。方向ボタンを長押しすると、ターンを進めずに向きだけ変えます。
隣の敵へ進むと攻撃。魔法と矢は主人公が向いている方向に放たれます。

PC：方向キー・WASD、Q/R/Z/Cで斜め移動。Shift＋方向で向きだけ変更。
Space：剣撃、F：星術、E：調べる・階段、I：持ち物、M：星図、.：待つ。
テンキーの1〜9にも対応しています。

ボスの赤い予告床は、次のターンに攻撃されます。安全な床へ移動して避けてください。
食事・装備変更・道具の使用も1ターン。商人の買い物と向きの変更は時間が進みません。

## セーブ

毎ターン、このブラウザのlocalStorageに自動保存します。ブラウザを閉じても「冒険を再開」で続きから遊べます。
「記録」からJSONファイルの書き出し・読み込み・直前の自動保存の復元ができます。

保存は端末とブラウザごとです。アカウントやクラウドセーブは使いません。
別の端末へ移る時はセーブファイルを送り、同じ公開URLで読み込んでください。
プライベートブラウズ・ブラウザのデータ削除ではセーブが失われるため、大切な記録を書き出して保管してください。

## ローカルで起動

Node.js 18以降で、このフォルダで `npm start` または `node server.mjs` を実行し、
`http://localhost:4173` を開きます。ライブラリのインストールは不要です。
ES Modulesを使っているため、index.htmlをダブルクリックする方式では起動できません。

検証：`npm test`。迷宮生成300回、戦闘・魔法・道具・装備・星座・ボスの回避・仲間・セーブ・読み込みを検証します。

## 制作と検証

ゲームの画像はCodexの組み込みimagegenで生成しました。
納品フォルダの `assets` に5つの画像と、それぞれの最終生成プロンプトを保存しています。生成プロンプトは公開用Gitリポジトリから除外しています。
キャラクター・魔物の透過アトラス、迷宮テクスチャ、世界背景をゲーム内で使用しています。
背景音と効果音はWeb Audioで合成します。音は初期状態ではOFFです。
フォントはGoogle Fontsを利用し、読み込めない場合は端末のフォントで動作します。

PC・タブレット・スマートフォン（320 / 375 / 390 / 768 / 1440幅）の実画面で、操作・自動保存・再開・書き出し・読み込み・仲間加入・施設・エンディングを検証。
ゲームロジックの21項目の検証に加え、4主人公のキャンペーン攻略シミュレーションを実施しました。
攻略シミュレーションは全地形を知る自動操作のため、人間による難易度・面白さの評価とは異なります。

本作はオリジナルのブラウザゲームです。商用コンソール作品と同等の物量や制作規模を保証するものではありません。
